 Gut microbiota and reproductive tissue transcriptome datasets from late-laying hens exposed to areca extract Data Package README
---

# 1. Overview

This data package contains processed 16S rRNA gene and RNA-seq data
generated from the study of late-laying hens fed 500 mg kg−1 areca nut
extract. The package is organized into 16S processed data, RNA-seq
processed data, and reproducibility information. The 16S component
contains 16 samples and 2,864 OTUs. The RNA-seq component contains 36
libraries from ovary, uterus and oviduct samples.

# 2. 16S processed data

## 2.1 Sample metadata

File: `16S processed data-Metadata`

This file contains sample-level metadata for the 16S rRNA dataset,
including sample identifiers and experimental/tissue or intestinal-site
information. It supports sample identity and traceability during
downstream analyses.

## 2.2 OTU abundance

File: `16S processed data-OTU abundance`

This file contains OTU abundance information for the retained 16S
samples. The processed dataset contains 2,864 OTUs across 16 samples and
provides the abundance information used for microbial-community
analyses.

## 2.3 Representative sequences

File: `16S processed data-representative sequence...`

This file contains representative sequences corresponding to the
retained OTUs. These sequences preserve the OTU-level sequence
definitions generated by the original clustering workflow and support
taxonomic assignment and independent reanalysis.

2.4 Taxonomy 

File: `16S processed data-taxonomy`

This file contains taxonomic assignments corresponding to the retained
OTUs. It links OTU identifiers to assigned taxonomic ranks and supports
taxonomic-composition and downstream microbial-community analyses.

# 3. RNA-seq processed data

## 3.1 Alignment results

File: `RNA-seq processed data-alignment`

This file contains reference-genome alignment statistics for the RNA-seq
libraries and supports assessment of genome-mapping performance.

## 3.2 Differential-expression results

File: `RNA-seq processed data-differential expres...`

This file contains detailed differential-expression results generated
from the RNA-seq dataset. It provides gene-level statistical results for
the comparisons performed in the original analysis workflow. This is an
analysis-result table and should be distinguished from the underlying
gene-level expression/TPM matrix.

## 3.3 Sample metadata

File: `RNA-seq processed data-Metadata`

This file contains metadata for the 36 RNA-seq libraries, including
sample identifiers, treatment/group information, tissue type and
biological-replicate information.

3.4 Correlation and PCA records

File: `RNA-seq processed data-correlation and PCA records`

This file contains sample-correlation and principal-component-analysis
(PCA) records for the RNA-seq libraries. The PCA records include
explained-variance information and sample-level PCA information,
supporting assessment of global sample structure and visualization.

3.5 Sequencing quality-control records

File: `RNA-seq processed data-QC sequencing-q...`

This file contains sequencing-quality-control statistics for the RNA-seq
libraries and supports assessment of sequencing quality before
downstream expression analysis.

# 4. Reproducibility information

## 4.1 Software versions and key parameters

File: `Software versions, key parameters`

This file records software/version information and key analysis
parameters relevant to the data-processing workflows. It is provided to
improve methodological transparency and facilitate reproducibility of
the processed datasets and downstream analyses.
